X Abuse Shield hides abusive posts on x.com — insults, threats, slurs and copy-paste troll brigades — before they appear on your screen. Everything runs in your browser: no account, no server, no data sent anywhere.

For **Chrome and Brave** on desktop, and **Firefox on desktop and Android**. Chrome and Brave install it from the files below; Firefox from Firefox Add-ons once the listing is published, or from the `.xpi` below.

## What's changed in 0.2.5

- **Firefox for Android support.** The same Firefox add-on now runs on phones and adapts itself there: finger-sized buttons, a full-screen popup, x.com's phone layout, and smaller batches so verdicts appear quickly while you scroll.
- **A lighter AI model for phones**: 93 MB to download instead of 289 MB, and about 330 MB of memory instead of about 630 MB, so it runs smoothly on a 6 GB phone. It covers English, Hindi, Hinglish, Urdu and Bengali; desktop keeps the full 34-language model.
- **Firefox Add-ons ready:** a permanent add-on id (`x-abuse-shield@downlz.github.io`) for the listing, so Firefox can install and update it normally.

Using an earlier Firefox `.xpi`? The new id makes this a different add-on: remove the old one in `about:addons`. To keep your settings and mutes, export them first (**Settings → Backup → Export**) and import them after installing.

## What it does

**Reads what a post says**
- An on-device AI model scores 7 kinds of abuse (toxicity, severe toxicity, threats, insults, identity attacks, obscenity, sexual content) in 34 languages.
- Built-in word lists for English, Hindi (Devanagari) and Hinglish see through disguises like `f*ck`, `fuuuck`, leetspeak and invisible characters.
- Catches threats without bad words ("I know where you live") and ignores harmless idioms ("kill it at your interview").
- Milder words (*pagal*, *idiot*) count only with other evidence, so friendly teasing gets through.
- Insulting emoji: 🖕, plus 🤡 and 💩 in replies from suspicious accounts.
- Reads long posts in full, including the text behind "Show more", and judges a quoted post on its own: if only the quote is abusive, only the quote is hidden.

**Looks at who is posting**
- Replies from days-old, low-follower, default-avatar or auto-generated-handle accounts face stricter thresholds. These signals never hide a clean post on their own.
- The same reply pasted by 3 or more accounts within minutes is caught as a brigade: if one copy is abusive, every copy is hidden.
- Accounts you follow never count as suspicious; optionally, they're never filtered at all.

**Deals with repeat offenders**
- 3 hidden posts in 7 days mutes the author automatically (24 hours to forever). Muted accounts are hidden everywhere, including their reposts and quotes.
- **Mute on X** clicks X's own mute for you, when you press it. Nothing else is done to your X account.

**Keeps you in control**
- Works on For you, Following, replies and Notifications, in light and dark themes.
- Hidden posts are blurred with **Show**, **Not abusive** and **Mute** buttons; threats are collapsed. Nothing is deleted or blocked.
- The **Hidden posts** page explains every decision, and one click marks a mistake as not abusive.
- Relaxed / Balanced / Strict presets, per-category sliders, your own word lists, an allowlist, and settings backup.

## Install

**Chrome or Brave**
1. Download `x-abuse-shield-0.2.5-chrome.zip` and unzip it into a folder you'll keep (for example `Documents\x-abuse-shield`). The browser loads the extension from that folder, so don't delete it.
2. Open `chrome://extensions` (Brave: `brave://extensions`) and switch on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder (the one containing `manifest.json`).
4. Reload any open x.com tabs.

About the `.crx`: Chrome on Windows and macOS won't install `.crx` files from outside the Chrome Web Store (dragging one in fails with `CRX_REQUIRED_PROOF_MISSING`). It's here for computers where a policy allows the extension by its id, `lbigjiokejckfhhnlbadmcdglfolkoln`.

**Firefox (desktop and Android)**

Once the Firefox Add-ons listing is published, install it from there: it's signed by Mozilla, stays installed, and updates itself. Until then, on desktop:

1. Download `x-abuse-shield-0.2.5.xpi`.
2. Open `about:debugging#/runtime/this-firefox`, click **Load Temporary Add-on…** and choose the `.xpi`.
3. Reload any open x.com tabs.

The file isn't signed by Mozilla, so regular Firefox removes it when you quit, and you load it again next time. Firefox Developer Edition and Nightly can keep it: set `xpinstall.signatures.required` to `false` in `about:config`, then install the `.xpi` from **about:addons → ⚙ → Install Add-on From File…**.

## First run

- The word lists work straight away.
- For the AI model, open the extension's popup and click **Download** (289 MB on desktop, 93 MB on a phone; use Wi-Fi). The popup shows the progress; it takes a minute or two, once. After that it loads in a few seconds from your browser's storage, uses about 500–630 MB of memory on desktop (about 330 MB on a phone) while x.com is open, and unloads after 5 idle minutes (3 on a phone). On computers that report 4 GB of memory or less it starts switched off.
- Settings are under **Settings** in the popup; hidden posts and their reasons under **Hidden posts**.

## Updating

There are no automatic updates. To update in Chrome or Brave, replace the files in the same folder with the new version's, then click the reload icon on the extension's card; your settings and mutes stay. In Firefox, load the new `.xpi`.

## Good to know

- Tested on desktop Chrome and Firefox, and on Firefox emulating a phone; not yet on a real Android phone. Brave runs the same build as Chrome. Edge may work but hasn't been tested.
- X changes its pages often. If the toolbar icon shows **!**, the extension can't read the page; please open an issue.
- Quote cards, reposts and the "Mute on X" menu were built from X's page structure as documented elsewhere and haven't all been checked on live x.com yet. Reports welcome.
- On a phone, the "!" warning has no toolbar icon to appear on; the popup shows whether the page can be read.
- The only network request the extension makes is the one-time model download from Hugging Face, after you click Download. Account details come from data x.com already loads into the page.
